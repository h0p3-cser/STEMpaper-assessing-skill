# paper-rubric-review

> 中文版 | [English](./README.md)

一份 10 维度的 STEM 论文评分框架,配两张雷达图和一套经过反复踩坑的自我审查流程。

## 这是什么

一个面向论文评分的框架。每篇论文会得到:

- 10 个维度分数 (0-100%)
- 加权总分 (0-100)
- 5 个宏观分数 (问题/方法/证据/表达/学术),同样 0-100 量纲
- 两张 SVG 雷达图 (一张宏观、一张分维度)
- 可选:与某份已发表期刊论文的实证分布做对照

输出是一段 markdown,内含分维度表格、两张雷达图、3-5 条优点、3-5 条带具体改法的弱点,以及一个「30 分钟内可以做的」具体行动。

这套评分是 STEM 通用版。理论物理、实验化学、生物化学、算法论文都用同一套 10 维度,只是每个维度下的「要看什么」按学科分了块。

## 10 个维度

| # | 维度 | 权重 |
|---|------|-----:|
| 1 | 选题创新性 | 20% |
| 2 | 方法原创性 | 15% |
| 3 | 方法严谨性 | 10% |
| 4 | 实验验证 | 15% |
| 5 | 写作规范性 | 10% |
| 6 | 结构与逻辑 | 5% |
| 7 | 文献覆盖 | 5% |
| 8 | 可复现性 | 5% |
| 9 | 表达与图表 | 5% |
| 10 | 潜在价值 | 10% |

总分 = Σ (分数 × 权重)。每个维度都按 0-100% 同一量纲打分,然后加权求和。权重之和 = 1.0。

每个维度的打分档位:

- 90-95% — 真正优秀,在金奖级论文里也会被列为优点 (上限 95%,不打 100)
- 75-89% — 强,达到可发表水准
- 60-74% — 可接受,但有几个能改的具体问题
- 40-59% — 重大问题,需要认真改一轮
- 20-39% — 缺少核心元素
- 0-19% — 缺失或起反作用

如果你在论文里找不到引文支撑某个分数,自动降一档。每个维度的完整档位描述在 `references/rubric.md` 里。

## 5 个宏观

10 个维度归并到 5 个宏观类,各自归一化到 0-100:

- **问题价值** — 维度 1
- **方法严谨** — 维度 2+3
- **证据强度** — 维度 4
- **论文表达** — 维度 5+6+9
- **学术价值** — 维度 7+8+10

宏观雷达图用这 5 个轴,分维度雷达图用全部 10 个独立轴。两张图量纲一致,可以互相对照。

「30 分钟内可以做的」应该对准最低的宏观项,不一定是最低的单个维度。一篇「证据 85 / 表达 50」的论文要先改写作,即使「可复现性」是单个最弱维度。

## 这套框架**不**做什么

这套框架不预测丘成桐/NeuIPS/ICML/ACL/CCF 的录取结果。早期版本里有一个「分数 → 金/银/铜」的映射表,那是没有校准数据拍脑袋写的,已经主动删掉。评分框架给的是自我审视视角,不是评委的判决。

有一份实证参考:12 篇被某期刊 (YSA 袁培 Young Scholars Journal Vol.10) 录用的 STEM 论文的 LLM 自评分分布。`references/calibration-data/README.md` 里写了这组数据的诚实使用规则。这是观察,不是门槛。

## 一个真实样例

这是某篇 LLM 幻觉检测论文的严格版评审。真实分数、真实输出格式。

| # | 维度 | 分数 |
|---|------|----:|
| 1 | 选题创新性 | 80% |
| 2 | 方法原创性 | 75% |
| 3 | 方法严谨性 | 72% |
| 4 | 实验验证 | 85% |
| 5 | 写作规范性 | 60% |
| 6 | 结构与逻辑 | 90% |
| 7 | 文献覆盖 | 75% |
| 8 | 可复现性 | 48% |
| 9 | 表达与图表 | 63% |
| 10 | 潜在价值 | 82% |
| | **总分** | **75.2** |

宏观:问题价值 80,方法严谨 73.8,证据强度 85,论文表达 68.3,学术价值 71.8。

绝对分位解读:75.2 / 100,整体偏强。研究内核扎实,剩下的都是润色级问题。

与 YSA-10 STEM (n=12) 实证分布对比:

- 总分 75.2 落在 YSA-10 分布的 91.7 分位 (中位数 65.5, IQR [59.0, 70.3])
- 论文表达 68.3 和学术价值 71.8 处于下半区 — 写作和可复现性才是真正的短板
- 研究侧 (问题/方法/证据) 都到了 IQR 之上

雷达图见 `examples/radar-5macro.svg` 和 `examples/radar-10dim.svg`。完整实证对比在 `examples/calibration-comparison.md`。

5-宏观雷达图是一个略偏研究侧的健康五边形;10-维雷达图把单个弱维度 (D5 写作 60% 和 D8 可复现 48%) 显出来。这就是双雷达的价值:宏观告诉你哪条腿短,分维度告诉你先修哪个单点。

## 怎么用

流程是 markdown 驱动的。LLM (或按流程走的人类评审) 读论文 → 应用评分 → 输出 markdown 评审。

生成雷达图:

```bash
# 5 宏观雷达图
node scripts/radar-chart.js '{"问题价值":80,"方法严谨":73.8,"证据强度":85,"论文表达":68.3,"学术价值":71.8}' --title "5-Macro Radar"

# 10 维雷达图
node scripts/radar-chart.js '{"D1 选题":80,"D2 方法":75,"D3 严谨":72,"D4 实验":85,"D5 写作":60,"D6 结构":90,"D7 文献":75,"D8 可复现":48,"D9 图表":63,"D10 潜力":82}' --title "10-Dim Radar"
```

与 YSA-10 实证参考对比:

```bash
python3 scripts/compare-calibration.py --level ysa10-stem \
  --scores "80,75,72,85,60,90,75,48,63,82" \
  --macros "80,73.8,85,68.3,71.8"
```

## 注意事项

- 单个分数有 ±8 分的噪声。LLM 自评分对 prompt 敏感,同一篇论文重跑一遍,任何维度会有 3-5 分浮动。这是已知下限,不是 bug。
- YSA-10 STEM 校准样本只有 n=12,只能算观察。样本里的 12 篇 STEM 论文在这套评分下长什么样,不构成「录用门槛」。
- 阅读纪律假设输入有可读文本或可栅格化的图片。纯扫描版 PDF 要先 OCR。Word .docx 里的公式经常需要重打或截图,因为文本提取会把它们打散。
